GPU Machine — run these first (2 terminals)

Terminal 1 — Ollama:
taskkill /F /IM "ollama app.exe"
set OLLAMA_HOST=0.0.0.0:11434
ollama serve

Terminal 2 — verify Ollama is bound correctly:
netstat -an | findstr 11434
# Should show 0.0.0.0:11434 LISTENING
